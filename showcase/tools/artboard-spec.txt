WHAT AN ARTBOARD IS
- One self-contained HTML file in showcase/art/, one fixed canvas: <div class="ab post"> (1080x1350) or <div class="ab story"> (1080x1920).
  Emails are different (see the email section).
- Head, in this order: <meta charset="utf-8">, <title>XXVIII · post 03 · Every steak lists its age</title>,
  <link rel="stylesheet" href="../../assets/css/brand.css">, <link rel="stylesheet" href="art.css">, then one inline <style> for this artboard only.
- art.css gives: .ab base, .handle, .lbl, .num, .disp, .pool (radial warm light), .vignette, .grain-ab (static grain), .cut-shadow, .still. Read it.
- Absolute px sizing only (no vw/vh/clamp/rem-based fluid type; the canvas is fixed). Headlines big: 110–260px Gloock. Labels 20–30px Big Shoulders 600, tracking .2–.3em, uppercase. Body 30–40px Hanken Grotesk. Nothing smaller than 20px.
- Fonts/tokens come from brand.css: var(--char) #141110, --char-2, --char-3, --ox #7a1e24, --ox-hi, --ox-deep #4a1216, --brass #c29a5b, --brass-hi, --brass-lo, --bone #efe7da, --ash #a39686, --line. NO other hues (no blue, green, violet, pure white/black). Brass text on oxblood fails contrast for small text: use bone there.
- Images (relative from showcase/art/): ../../assets/img/plated/<slug>-lg.webp (square 1600, dish on dark walnut table, oxblood booths and brass lamps behind) and ../../assets/img/cutout/<slug>-lg.webp (plate on transparency, trimmed). STORIES / ANIMATED ARTBOARDS
- CSS keyframes or GSAP (<script src="../../assets/vendor/gsap.min.js"></script>) loops of 6–10 s, slow and weighted (power2/power3, nothing bounces). Loop seamlessly.
- If location.search contains "still=1": render the REPRESENTATIVE frame (the message fully visible, counters at their final value) and stop all motion: e.g. document.documentElement.classList.add('still'), tl.progress(0.85).pause(), or apply final-state classes. The exporter screenshots after ~1.4 s.
- prefers-reduced-motion: show the same still frame.
- Generic platform UI only (thin progress bars at top, a poll sticker, link sticker, countdown sticker drawn by you in neutral style). NO real Instagram/Facebook/TikTok logos or brand names on the artboard.

HOW TO CHECK YOUR WORK (mandatory)
- Render: python C:\Users\leuss\ClaudeWork\xxviii-steakhouse\showcase\tools\render.py post-03 post-04   (names = file stems; ad files ad-feed-N / ad-story-N; emails email-<name>). It prints OK/FIX with text-fit issues and writes showcase/exports/<kind>/<name>.png. It picks its own ports; several can run in parallel.
- Read EVERY PNG you produce with the Read tool and judge it as an art director: hierarchy, balance (no dead empty half, no cramped edges), contrast, overlap, photos not stretched, nothing generic. Fix and re-render until FIX count is 0 and it looks premium. Two rounds of fixes max per artboard, then move on.
- Do NOT edit anything outside your assigned files. Do NOT edit art.css, render.py, assets/, or other artboards. No git commits. Don't start servers (render.py is self-contained).
